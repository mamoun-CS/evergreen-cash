# EverGreen CASH — دليل التشغيل والتوثيق الفني للمنظومة

تطبيق محاسبي وإداري متكامل لإدارة الصندوق المالي والخدمات الزراعية لشركة **EVER GREEN AGRICULTURAL CONTRACTORS**، مصمم خصيصاً لأجهزة **Apple iPad** ويعمل بنظام **تطبيق ويب تقدمي (PWA)** بدون خادم مركزي للعمليات اليومية (**Offline-First**).

---

## 1. البنية المعمارية والتصميم

1. **الواجهة وتجربة المستخدم**:
   - واجهة متجاوبة ومبنية بحجم أزرار ولمس مهيأة لأجهزة iPad (أهداف لمس 48px فما فوق).
   - واجهة عربية أصيلة مع دعم كامل للاتجاه من اليمين لليسار (`dir="rtl"`).
   - خطوط عربية محملة محلياً (`Cairo`) مع ألوان الشركة الرسمية (الأخضر الغابي، الليموني، والأبيض الكريمي).

2. **قاعدة البيانات المحلية (IndexedDB)**:
   - مدعومة بـ Dexie.js ومفهرسة بالكامل مع مخطط تزايدي (Schema Versioning).
   - سجل مالي تسلسلي لا يقبل الحذف التراجعي (**Append-Only Ledger**) ومترابط برمز تشفير SHA-256 (`prevHash` و `hash`).
   - دقة حسابية دقيقة بوحدات المبالغ الصغرى الصحيحة (`Minor Units / BigInt`) لتفادي أخطاء الفاصلة العائمة (IEEE Floating Point).

3. **النسخ الاحتياطي والاسترجاع السحابي**:
   - تشفير متقدم بمستوى أمني عالي **AES-256-GCM** مع اشتقاق المفتاح عبر **PBKDF2** (مع 310,000 دورة تكرار).
   - المزامنة إلى Postgres اختيارية ومحمية بمفتاح خادم، وترفع كتلة مشفرة من الطرف إلى الطرف. نسخ Google Drive غير مطبقة حالياً.
   - إمكانية التصدير والاستيراد لملفات النسخ المشفرة (`.egc`) محلياً بدون إنترنت عبر تطبيق ملفات Apple أو AirDrop.

4. **توليد الفواتير والتقارير PDF**:
   - محرك توليد ملفات PDF متوافق مع الحروف والأشكال العربية المتصلة (`arabic-reshaper` و `bidi-js`).
   - دعم مباشر للمشاركة السريعة عبر الـ Share Sheet لنظام iPadOS والطباعة الفورية.

## 2. أقسام وشاشات المنظومة

| الشاشة | المسار | الوظيفة |
| :--- | :--- | :--- |
| **لوحة التحكم** | `/` | أرصدة الصندوق اللحظية، المقبوضات والمصروفات، السلف المستحقة، المخطط البياني التفاعلي، والتنبيهات. |
| **الحركات النقدية** | `/transactions` | تسجيل القبض، الصرف، السلف، تسوية واسترداد السلف، ورصيد البداية، مع إمكانية عكس الحركات بقيود تسوية. |
| **دليل الأشخاص** | `/people` | إدارة الموظفين والمقاولين والعملاء، استعراض كشوف الحسابات الفردية وتصديرها بصيغة PDF. |
| **إدارة الفواتير** | `/invoices` | إنشاء المسودات، الفواتير المعتمدة، التكرار، الإلغاء، ومتابعة حالة التحصيل مع تصدير PDF رسمي بالهوية الزراعية. |
| **الجرد والمطابقة** | `/reconcile` | مطابقة النقد الفعلي بالخزينة مع الرصيد الدفتري التراكمي وتوليد قيود تسوية الفروقات آلياً. |
| **التقارير التحليلية** | `/reports` | تقارير الصندوق، الإيرادات، المصروفات، السلف، الفواتير، والجرد مع فلاتر زمنية وتصدير CSV و PDF. |
| **النسخ الاحتياطي** | `/backup` | تصدير واستعادة ملف `.egc` مشفر وفحص بصمته وسلسلة السجل المالي. |
| **إعدادات النظام** | `/settings` | هوية الشركة، العملات، ترقيم الفواتير، قفل التطبيق السريع (PIN Lock) ومهلة القفل التلقائي. |

## 3. تعليمات التثبيت والتشغيل على بيئة Windows

1. **المتطلبات الأساسية**:
   - Node.js (إصدار 20 فما فوق).
   - مدير الحزم npm.

2. **تشغيل بيئة التطوير**:
   ```powershell
   npm install
   npm run dev
   ```
   التطبيق سيعمل محلياً على: `http://localhost:3000`

3. **التحقق من الفحص والإنتاج**:
   ```powershell
   npx eslint
   npx tsc --noEmit
   npx vitest run
   npx next build
   ```

## 4. إعداد المزامنة على Vercel

1. أضف رابط Postgres في `POSTGRES_URL` أو `DATABASE_URL`.
2. أنشئ قيمة طويلة وعشوائية لـ `SYNC_API_KEY` في متغيرات بيئة Vercel.
3. على كل جهاز افتح الإعدادات وأدخل المفتاح نفسه وعبارة مرور مزامنة من 10 أحرف على الأقل. احفظها في مدير كلمات مرور آمن لتكرارها على الأجهزة.
4. المزامنة تحتاج اتصالاً نشطاً؛ iOS لا يضمن تشغيل مهام خلفية بعد إغلاق التطبيق. جهّز نسخ `.egc` مستقلة بانتظام.

---

## 5. تثبيت التطبيق على جهاز Apple iPad (PWA)

1. افتح رابط التطبيق المنشور على خادم HTTPS عبر متصفح **Safari** على جهاز iPad.
2. اضغط على زر **المشاركة (Share)** في أعلى المتصفح.
3. اختر من القائمة: **"إضافة إلى الشاشة الرئيسية" (Add to Home Screen)**.
4. سيظهر تطبيق **EverGreen CASH** كأيقونة مستقلة على شاشة الـ iPad الرئيسية.
5. يعمل التطبيق بعد ذلك بوضع ملء الشاشة المستقل ويدعم العمل الكامل عند انقطاع الإنترنت بفضل تقنية الـ Service Worker وقاعدة بيانات IndexedDB المحلية.
